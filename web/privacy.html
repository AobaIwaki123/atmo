atmo プライバシーポリシー

最終更新日: 2026年10月28日

本プライバシーポリシーは、Aoba Iwaki（以下「当開発者」）が提供するアプリケーション「atmo」（以下「本アプリ」）における利用者情報の取り扱いについて定めたものです。

1. 取得する情報とその目的

本アプリは、サービスの提供および機能向上のために以下の情報を利用します。

  • 位置情報（緯度・経度）: 利用者の現在地における気圧データ、24時間気圧推移グラフ、および気圧急変に伴うアラート情報を正確に取得・表示するために利用します。

2. 外部送信および第三者提供

本アプリは、現在地の気象・気圧データを取得するため、以下の外部サービスと通信を行います。

  • Open-Meteo API: 気象・気圧予測データの取得
  • atmo バックエンド API (atmo.aooba.net): 自治体名逆引き（Nominatim 連携）および空間気圧データキャッシュの提供

送信されるデータは緯度・経度情報のみであり、氏名、メールアドレス、電話番号、端末固有識別子などの個人を特定可能な情報は一切含まれません。また、取得した情報を広告配信や行動追跡等の目的で第三者に提供・販売することは一切ありません。

3. データの保存と破棄

送信された位置情報は、リアルタイムの気圧データ取得および空間キャッシュの生成にのみ一時的に利用され、サーバー上に個人の行動履歴として永続的に保存・蓄積されることはありません。

4. 位置情報の利用許可と停止

利用者は、端末の設定より本アプリによる位置情報の利用をいつでも許可または停止することができます。
